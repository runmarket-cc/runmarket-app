# Android 러닝 터치 잠금 검증

관련 이슈: https://github.com/runmarket-cc/runmarket-app/issues/55

터치 잠금은 Android 러닝 화면의 입력만 차단한다. 운동의 running/paused 상태,
GPS 수집, 소켓 전송, 로컬 기록은 변경하지 않는다. 시스템 홈·알림창·전원 버튼은
계속 사용할 수 있다. 잠금은 현재 화면의 메모리 상태이며 앱 재시작 후 복원하지 않는다.

## 실기기 확인 항목 (미실행)

- 시작 전에는 잠금 버튼이 없고, 러닝 시작 후 표시되는지 확인한다.
- 달리는 중 잠그고 지도 드래그·확대, 러너 선택, 그룹 코드 복사, 위치 재중심,
  일시정지·정지, 헤더 뒤로가기가 모두 차단되는지 확인한다.
- Android 뒤로가기 버튼 및 뒤로가기 제스처로 잠금이나 러닝 화면이 닫히지 않는지 확인한다.
- 잠금 중에도 시간·거리·페이스가 갱신되고 관전자에게 위치가 전달되는지 확인한다.
- 해제 버튼을 짧게 누르거나 연속으로 누르면 잠금이 유지되는지 확인한다.
- 2초 전에 버튼 밖으로 손가락을 이동하거나 손을 떼면 해제되지 않는지 확인한다.
- 2초간 연속으로 누르면 해제되고, 같은 터치가 지도나 운동 버튼에 전달되지 않는지 확인한다.
- 해제 도중 홈 이동·알림창 열기·화면 끄기를 수행하고 복귀하면 잠금이 유지되며,
  새로 2초간 눌러야 해제되는지 확인한다.
- 일시정지 상태에서 잠금·해제해도 운동 시간이 증가하거나 자동 재개되지 않는지 확인한다.
- 잠금·해제를 여러 번 반복하고 종료한 뒤 다시 시작하면 잠금이 초기화되는지 확인한다.
- 작은 화면·큰 글꼴에서 통계와 해제 버튼이 보이는지, TalkBack의 길게 누르기 동작으로
  해제할 수 있는지 확인한다.
- iOS에는 잠금 버튼이 없고 기존 러닝 동작이 유지되는지 확인한다.

## 정적 검증

npx tsc --noEmit
